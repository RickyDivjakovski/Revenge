# Mixed shader fixture compiler and pipeline cache

This is an independent fixed compute fixture ABI, not a console ABI. Public GFX10.3 encodings are reused from the existing flow and buffer decoders. In mixed mode v0 is an immutable dispatch index, s0 is group ID, s[4:7] is the input descriptor group and s[8:11] is output. Descriptor groups are reserved and are not decoded. t0 and u0 refer to disjoint buffers of 4096 dwords; input out-of-bounds reads are zero. Only aligned immediate offsets, idxen, inline zero scalar offset and one dword per operation are supported.

The single forward CFG validator intersects defined-register sets at joins and tracks whether an output store may or must have occurred. Pending loads cannot cross a branch or merge, and all paths must store exactly once. No backward branches, divergent masks, real console descriptor layout, textures, or general memory hazards are handled. Normal finite FP32 restrictions are unchanged. The previous ALU and buffer compilers remain separate for regression tests.

The optional `shader-unified-gpu-test cache/unified.pso` command compiles HLSL as cs_5_1, creates a compute PSO and compares GPU outputs with an independent oracle. The local PSO cache envelope includes exact shader bytes, serialized root signature, adapter identifiers, schema version and driver version when DXGI supplies it. It bounds lengths and checks a non-cryptographic integrity checksum; this is not authentication. Only use private local cache files. The driver validates opaque PSO data; on rejection normal PSO creation is retried. Cache writes use temporary file replacement after successful output verification. Cache may miss across reboots or driver changes. No claim of improved FPS or avoided HLSL compilation. Graphics PSO caching remains pending.

Public references: [AMD RDNA2 ISA](https://gpuopen.com/news/rdna2-isa-available/), [D3D12 cached PSO](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/ns-d3d12-d3d12_cached_pipeline_state), [GetCachedBlob](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/nf-d3d12-id3d12pipelinestate-getcachedblob).
