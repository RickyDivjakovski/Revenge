# v0.18.0 indexed scene fixture

`gpu-scene-test [width=1280] [height=720] [output.bmp]` (Windows hardware D3D12). Extent is 320–3840 by 240–2160. Optional BMP overwrites that path. No monitor or swap chain is required. The GPU command renders a single frame, not a throughput benchmark.

The independent command list validates begin, mesh/texture binding, indexed draw ranges and end. It is interpreted by the D3D12 fixture; bindings are fixed to one mesh and one texture. Vertex/index buffers use upload heaps. The graphics pipeline uses a point-clamp sampler, a 2×2 RGBA8 texture, D32_FLOAT depth and a perspective projection. Two quads at z=1 and z=2 are submitted near-first and far-second. The resulting depth rejection is observable because the near quad has four texture colours and the rear quad is yellow. The color target is transitioned to COPY_SOURCE and copied to a readback buffer; GPU fence completion precedes Map. The CPU oracle checks interior pixels while excluding near-edge and sample-tie positions. It checks colors and occlusion, not exact boundary rasterization. The portable tests generate their own synthetic images, not captured GPU data.

Windows GPU execution is pending; current fixture uses independently authored desktop HLSL, not translated RDNA2 graphics instructions. There is no generic resource handle dispatch, arbitrary camera, cube mesh, cross-queue synchronization, GPU descriptor allocator, scene PSO cache, or Xbox ABI. The scene is offscreen, separate from the existing animated triangle presentation path.
