# Translated resident stage programs

RV_GPU_DRAW_PROGRAM (78), capability RV_GFX_RESIDENT_PROGRAM (1024), accepts the same request fields as RV_GPU_DRAW_INDEXED plus exactly one rv_gpu_program packet. Both stage counts must be 1–256 words. The existing restricted stage decoder rejects unsupported encodings, malformed exports and missing termination. The vertex wrapper supplies float2 position, z=1 and UV derived from clip-space XY; the pixel stage samples resident t0 with point-clamp s0. This is an independent experimental stage interface, not a console ABI. All existing resource constraints apply.

The backend compiles emitted HLSL to shader model 5.1 and caches up to 16 distinct source pairs per arena. RV_GPU_PROGRAM_COUNT (79) takes an empty request and reports cached pair count (zero before allocation and after stop). Repeated pairs reuse the PSO. Cache exhaustion returns RV_RANGE. Draws are synchronous, use the existing fence and clear the target. RV_GPU_PROGRAM_CREATE (80) takes a program packet with all request fields zero (except the standard header/op) and returns an independently managed pipeline handle. RV_GPU_PROGRAM_RELEASE (81) takes that handle only; RV_GPU_DRAW_PIPELINE (82) takes standard indexed draw fields and an exact uint64_t pipeline handle as input. RV_GPU_PROGRAM_HANDLES (83) reports live handles. Up to 16 handles per session; duplicate pairs share one cached PSO. Releasing a handle does not evict the cached pair; stop/close clears both. RV_GPU_PROGRAM_CLEAR (84) takes an empty request, requires a running session with no live program handles, clears translated PSOs only and returns the number removed. The legacy fixed PSO is preserved. No independent per-stage handles, arbitrary shader inputs, dynamic constants for translated stages, batching or general console shader translation are implemented.

The fixture checks malformed packets without a GPU, and on Windows compares 1,620 pixels from eight new draws, including channel swizzle, identity output, narrowed geometry and cache reuse across extents. Hardware validation pending.
